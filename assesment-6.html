The Data Breaches

Summary

Data Breaches is one of the 3 Doomsday heists. Lester and Avon ask you to help the IAA stop foreign country hackers from stealing top-secret files that could destroy the world if they get them.

Payout

The full payout for this heist on hard mode with the first-time weekly bonus is $1,340,381. With a 55% share, the host receives $737,210. If you do it as a duo, the crew's cut is 45% and each member gets $603,171. If you do it with a squad using the 40-20-20-20 split, the host gets $536,076 and each crew member gets $268,076.
