The Bogdan Problem

Summary

Bogdan Problem is one of the 3 Doomsday heists. Lester and Avon ask you to launch an operation on a foreign submarine lurking off the coast. One team boards through the airlock and disables the sub, while the other holds off enemy agents in an aircraft above.

Payout

The full payout for this heist on hard mode with the first-time weekly bonus is $1,959,019. With a 55% share, the host receives $1,077,460. If you do it as a duo, the crew's cut is 45% and each member gets $881,558. If you do it with a squad using the 40-20-20-20 split, the host gets $783,607 and each crew member gets $391,803.
